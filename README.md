# Speaker Cleaner (iOS 17+, Swift 6.0)

Премиальное iOS-приложение для резонансной акустической очистки динамиков мобильного устройства от воды и пыли, спектральной аппаратной диагностики и безопасного ухода.

---

## 🌊 Режимы очистки

1. **Вода (Water Eject):**
   - **Частотный диапазон:** 140–165 Гц (резонанс подвижной системы динамика смартфона).
   - **Импульсная модуляция:** Пачки звука 450 мс с паузами 150 мс для создания ударного перепада давления воздуха.
   - **Haptic Boost:** Синхронная отдача вибромотора на `CoreHaptics` для разрушения сил поверхностного натяжения капель.

2. **Пыль (Dust Shaker):**
   - **Частотный свип:** 100 Гц → 10 000 Гц.
   - **Форма волны:** Меандр и пилообразная волна, генерирующие богатый спектр высокоэнергетических гармоник.
   - **Эффект:** Микровибрация сетки динамика для стряхивания сухих микрочастиц.

3. **Pro-режим (Ручной синтезатор):**
   - Точная плавная регулировка частоты от 20 Гц до 20 кГц (логарифмическая шкала).
   - Выбор формы волны: Синусоида, Меандр, Пила, Треугольник.
   - Настраиваемый строб / импульсный LFO.
   - Быстрые пресеты калибровки.

---

## 🔬 Диагностика и функции

- **Раздельный тест каналов:** Независимая подача звука на нижний мультимедийный динамик (`overrideOutputAudioPort(.speaker)`) и верхний разговорный спикер (`overrideOutputAudioPort(.none)` в режиме `.playAndRecord`).
- **Спектральный анализ отклика микрофона (FFT):**
  - Использование Apple Accelerate (`vDSP`).
  - Разложение спектра на 24 полосы в реальном времени.
  - Оценка чистоты динамика (0–100%) по трем диапазонам (Bass, Mid, Treble).
- **Автоматический контроль громкости:** Мониторинг выходного уровня `outputVolume` с предупреждением пользователя при уровне ниже 100%.

---

## 📚 База знаний и гайды

- **Механическая очистка:** Пошаговое руководство по очистке ультрамягкой щеткой под углом 45° с точечным нанесением 99.9% изопропилового спирта.
- **Инструкция при падении в воду:** Алгоритм экстренных действий (выключение, вертикальное положение динамиками вниз, запрет зарядки).
- **Дисклеймеры безопасности:** Запрет иголок/булавок, медицинского спирта 70%, фенов, риса и компрессоров высокого давления.

## 🛠 Сборка проекта через XcodeGen

Для генерации `.xcodeproj` файла:

```bash
cd SpeakerCleaner.ios
xcodegen generate
```

Затем откройте `SpeakerCleaner.xcodeproj` в Xcode 15/16+ и запустите на симуляторе или реальном устройстве.
